# Crunchies Fried Chicken Website Recreation

Beginner-friendly multi-page HTML/CSS/JavaScript student project.

## Files
- index.html — homepage
- menu.html — menu, filters and demo cart
- about.html — about page
- contact.html — contact page
- style.css — all styling
- script.js — mobile menu, newsletter/contact messages, menu filtering and demo cart

## Run locally
Open `index.html` in a browser.

## Hosting
This project can be uploaded to GitHub and hosted with GitHub Pages.

This is a student recreation for educational purposes and is not the official Crunchies website.
